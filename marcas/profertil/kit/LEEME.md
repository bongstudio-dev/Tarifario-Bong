# Kit de marca Profertil

Este kit es el Manual de Marca de Profertil (v1.1.4, julio 2026) en un formato
que **una persona puede hojear y un agente puede leer**. Las mismas reglas, con
su porqué, para quien arma una presentación un martes a la tarde y para Claude
cuando se la piden.

El manual en Figma es el canon. Si algo de este kit no coincide con el manual,
manda el manual y se corrige el kit.

## Cómo usarlo: ¿qué necesitás hacer?

| Necesito... | Leé | Manual |
|---|---|---|
| Hacer una presentación | `aplicaciones.md` | Sección 07 |
| Saber qué colores uso | `direccion-de-arte.md` | Sección 03 |
| Resolver una duda del logo | `direccion-de-arte.md` | Sección 02 |
| Escribir como Profertil | `voz.md` | Sección 01 |
| Publicar en redes o armar un newsletter | `aplicaciones.md` | Sección 08 |
| Entender quiénes somos y para quién hablamos | `estrategia.md` | Sección 01 |
| Saber por qué algo es así | `decisiones.md` | Brief y manual |
| Descargar recursos | Sección Recursos del manual o SharePoint | Sección 09 |

`../marca.json` tiene los valores (colores con HEX, RGB, CMYK y Pantone,
combinaciones, tipografías, íconos, recetas por tarea). Lo leen las
herramientas; las personas, por las herramientas.

Lo marcado *(borrador)* lo escribió Bong a partir del manual y del brief, pero
el manual no lo dice con esas palabras. Lo marcado *(pendiente)* todavía no está
cargado.

## Cuando el manual no lo cubre

El propio manual lo dice: *intentá usar los recursos de este manual, estos te
van a dar un punto de partida y lineamientos claros para crear algo nuevo.* Para
hacerlo bien:

1. **Buscá la regla más cercana y su porqué.** Si el porqué aplica a tu caso, la
   regla también.
2. **Si dos reglas chocan, gana la que protege el logo y la paleta.** Son lo que
   hace que todo se sienta Profertil en primera lectura.
3. **Elegí lo más simple que funcione.** El sistema tiene que simplificar la
   producción, no complicarla: primaria antes que terciaria, una forma antes que
   tres.
4. **Decí que fue una decisión tuya, no del sistema**, y anotala (en el MCP:
   `reportar_hueco`). Lo que se repite entra al kit en la próxima versión.
5. **Validala con Comunicaciones Integradas** (en el MCP: `responsables`).

## Para agentes

Leé este archivo y después solo las secciones que pida la tarea
(`que_necesitas_hacer` las indica en `leer`). Cuando una regla frene lo que la
persona quiere, explicale el porqué, no solo la regla. Las formas y los íconos
del MCP son reconstrucciones provisorias: avisalo si los usás en una pieza que va
a salir.
