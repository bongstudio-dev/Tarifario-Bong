# Fotos del caso Profertil

Cada ventana de `caso-profertil-maqueta.html` busca acá su archivo. Si está,
reemplaza sola la reconstrucción en SVG que se ve mientras tanto. Si no está,
no pasa nada: queda la reconstrucción. No hay que tocar el HTML.

El nombre tiene que ser exacto. Formato JPG (el `.jpg` está en el `data-foto`
de cada ventana; si querés PNG o WebP hay que cambiarlo ahí).

## Por qué no están

El entorno donde se armó esta maqueta tiene bloqueado el egress a `figma.com`
por política de red, así que las imágenes no se pudieron bajar desde el archivo.
Se exportan a mano desde Figma, o se habilita el host en la política de red del
entorno y se vuelven a pedir.

Archivo de origen: `KmNgyx8rr2CvjZa1hwTdSM`, página del caso Profertil.
